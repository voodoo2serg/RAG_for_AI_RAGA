# Contributing

Thanks for helping make AI context portable.

1. Open an issue describing the user problem and proposed behavior.
2. Make focused changes, keeping private or proprietary research code out of this repository.
3. Add or update tests and run them from the backend directory using python -m pytest -q.
4. Document new API endpoints in the README and interactive OpenAPI docs.
5. Prefer small, auditable adapters and clear error handling over hidden automation.

Areas for contributions: importers, SKILL.md workflows, manual review UX, portable exports, secure local deployment, integrations and deterministic evaluation.
